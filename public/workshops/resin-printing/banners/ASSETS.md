# Resin printing module banners (v01)

Ultra-wide **1915 × 821** (21:9) illustrative banners for HTML title overlays.

| Use | Path |
|---|---|
| Production | `*.webp` (flat) and `webp/*.webp` |
| Masters | `png/*.png` |

Art direction: museum-editorial 3D still life; subject center-right; left ~40% calm for live HTML. No baked-in text, logos, or brand UI. These are **illustrations**, not safety docs, slicer screenshots, machine photos, or failure evidence.

Regenerate only with the shared stylized-concept prompt rules in the banner set brief.
