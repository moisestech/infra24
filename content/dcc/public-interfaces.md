# DCC Public Interfaces

Public interfaces are the ways DCC shows work beyond private studios: websites, signage, QR handoffs, open labs, and network pages.

## Signage and QR

Staff can draft signage copy with the Memory Agent. Public mode and QR handoff require approval so incomplete or sensitive fields do not reach the floor.

## Network page

The public `/network` surface lists pathways into the Index, workshops, and events. Admin tools remain gated.

## Documentation ethos

DCC prefers clear, honest documentation over hype. AI tools are framed as assistants with governance, not autonomous publishers.
