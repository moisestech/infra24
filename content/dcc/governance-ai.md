# DCC Governance and AI

## Pilot scope

The Institutional Memory agent is a governed pilot. It answers from Airtable CRM, programming records, and DCC docs—not from payment, HR, or contract systems.

## Public outputs

Anything destined for QR, signage, or public screens requires human approval. The Network Readiness Agent writes drafts to Agent Approvals; it does not auto-send email.

## Evaluation

Golden Q&A fixtures and grounding checks (`npm run eval:memory-agent`) catch fabricated IDs and empty-context answers. Eval is part of demo readiness, not a claim of production-scale reliability.

## What production would add

Ownership, hosting SLA, privacy review, staff training, broader corpus coverage, and monitoring.
